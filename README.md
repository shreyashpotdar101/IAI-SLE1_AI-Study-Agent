# AI Study Assistant Agent

## 📌 Project Overview

AI Study Assistant Agent is a basic rule-based study assistant developed using Python.

The agent accepts a study-related request from the user, analyzes the request using keywords, and selects an appropriate action such as explaining a topic, generating quiz questions, creating a summary, or preparing a study plan.

---

## 🎯 Objectives

- To understand the basic concept of an AI agent.
- To implement a simple agent using Python.
- To process user requests.
- To provide basic study assistance.
- To demonstrate AI-assisted coding using ChatGPT.
- To document AI contributions during development.

---

## ✨ Features

The AI Study Assistant provides:

- 📚 Topic explanation
- ❓ Quiz question generation
- 📝 Topic summarization
- 📅 Five-day study plan
- 💡 Study tips
- ⚠️ Empty input handling
- 🚪 Exit command
- 🔄 Continuous interaction
